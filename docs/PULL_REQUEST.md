# Add 150 LPDP questions, shared stimuli and full 2026 practice simulation

LPDP previously had only 30 three-option introductory questions and could not run its full simulation. This change supplies 150 original five-option SBAs (50 verbal, 50 quantitative, 50 problem solving), five shared original reading passages, and 20 table/graph stimuli. Each category has the requested difficulty/topic distributions and balanced A–E keys, with steps, distractor rationales, tips and editorial status.

Adds strict validate:lpdp checks and 110 independent numerical, truth-table and exhaustive-constraint computations; shared-resource rendering/validation; complete LPDP_TBS_2026 selection and timing; configurable application practice points (default +5/0/0, 300 for 60 correct); per-subtest results; real-history recommendations and review scheduling; and metadata-safe JSON/CSV import/export. The former LPDP records are archived so old attempts, bookmarks and notes keep their original meaning. BTKV and SIMAK source question files are unchanged.

All LPDP content remains **needs_review**. Five similar-text pairs are flagged for editorial assessment. Difficulty/time labels are estimates. The 2026 structure comes from the brief; official-source verification is pending because LPDP source access was blocked by network policy. No official score scale or passing grade is claimed.

Validation: `npm run validate:lpdp` passes (150 questions and 110 independent reasoning checks); `npm run validate:btkv` passes; `npm test` passes 41 tests; `npm run build` and `npm run format:check` pass; all ten Chromium journeys pass, including full LPDP section progression, restored results and offline passages/tables. The global 550-question gate still fails at 350 because 200 SIMAK questions remain outside this change. No deployment was performed. See docs/LPDP_EDITORIAL.md and docs/lpdp-validation.json for verification coverage and limitations.
